# 📘 Markdown（.md）语法学习笔记

---

## 🧩 一、什么是 Markdown
Markdown 是一种轻量级标记语言，用于快速编写文档（README、笔记、博客等）。

特点：
- 写法简单
- 可读性强
- 可转换为 HTML / PDF

---

注意：
- `#` 后面必须加空格
- 不要写成 `#标题#`

## 十，分割线🎯 （Horizontal Rule）

---


## 十一，任务列表📝 （Task List）

任务列表可以标记完成或未完成状态，非常适合记录待办事项或项目进度。

### 基本用法
```markdown
- [x] 已完成任务
- [ ] 未完成任务
- [ ] 待办任务
```
- [x] 已完成任务
- [ ] 未完成任务
- [ ] 待办任务
