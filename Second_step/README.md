# 数据结构与算法

## 1,线性表（数组🧮

***数组***

特点：内存是连续的
---
- 优点：

    - 下标访问的时间复杂度是O（1）
    - 末尾位置增加删除元素的时间复杂度是O（1）
    - 访问元素前后相邻位置元素非常方便

- 缺点：
    - 非末尾位置增加和删除元素需要进行的量的数据移动
    - 搜索的时间复杂的度
        - 无序数组-线性搜索O（n）
        - 有序数组-二分搜索O（logn）
    - 数组扩容消耗比较大
        - 扩容

---
### 什么是***查找/搜索***？

从数组的第一个元素0开始，遍历数组内每个元素，直到发现所需的元素，及时查找。
```cpp
int a[2]= {1,1}
```
在这里面，第一个元素0对应着1，第二个元素1对应着2。
```cpp
int a[2]= {1,1}
int value = 1

for (int i=0;i<10,i++)
{
    if (a[i]==value)
     ......
}
```
未知下标，通过元素内的值（Value）来寻找元素
时间复杂度为On

---
### 什么是***下标访问***？
下标  是用来标识元素位置的数字。

下标访问 就是通过这个编号来获取或修改数组中的元素。

已知通过元素来寻找元素内的值（Value）

时间复杂度为O1

---

在数组末尾进行增加或者去除某一个值，相当于在进行下标访问，所以时间复杂度为O1，可以使用后cur来记录数组之中有效值（元素）个数。
```cpp
nums = [10, 20, 30, 40]

for cur in nums:
    print(cur)
```
cur后面可以为元素和下标
